# LUNAR-SWING 研究总结报告严格周期解、摄动演化与低近地点族域勘测




## 第一篇　研究总览


## 1.1 研究缘起与问题链

LUNAR-SWING 的原始概念（2026-04 版项目文档 [12]）提出一条颇具想象力的轨道机制：低近地点（≤200 km）大气穿越耗散能量，而远地点附近的月球借力补充能量，两者在 2:1 共振相位下形成“无燃料轨道维持”的能量平衡。该概念在原理上成立与否，涉及两个层次的问题：其一，**严格周期解是否存在且可被数值求解**；其二，**真实摄动环境下该机制是否可实现**。原始项目的概念文档齐备，但结果目录为空、原型解的速度残差达 0.20（未闭合）——本报告记录的研究工作正是从这一现状出发，把大问题拆成两轮由证据牵引的专题：

- **LS 专题**：先把 2:1 共振族做到判据严格的周期解，并完成首次 30 天高保真摄动演化，回答“是否有界”；
- **AS 专题**：把求解与演化推进到概念所要求的低近地点几何，回答“族是否存在、能量账本是否闭合”。

## 1.2 直观导读：三张图看懂这项研究

> 本章写给非航天动力学专业的读者；严谨表述与判据以后续各篇为准。

“大气阻尼—月球借力”的机制可以用图~\ref{fig:1-2} 一眼看懂：航天器沿一条很扁的大椭圆运行，**近地点**贴着地球大气层上缘飞过、每圈损失一点能量（阻尼）；**远地点**则安排在与月球轨道相近的位置、借月球引力把能量补回来。若两者恰好相抵，轨道便可“自持”。概念要求航天器每绕地球两圈、月球恰好绕一圈（即 2:1 共振），使每次相遇的几何重复出现。近地点在真实比例下紧贴地球、图中无法看清，故在右侧放大示意。

## 1.3 方法与组织

全部工作采用“设计组—专家组—质量组”三角色机制与测试驱动开发（TDD）：立项件、红基线、变更单（CR）、里程碑评审与监督记录全程留档 [1][2][5][6][7][10][11]。研究结论只以可复算的证据为依据；**负结果同样按留档规范交付**（AS 专题的族域勘测即为一例）。

## 第二篇　严格周期解与摄动有界性（LS 专题）


## 2.1 问题与目标

LS 专题把“原型解”推进为**判据严格**的周期解：半周期垂直截面残差、全周期全状态闭合、Jacobi 漂移三项同时约束；初值须由系统化网格扫描给出（无人工特调）；并把严格解搬入“J2–J4 + 真实月球星历 + 简化大气”的高保真模型演化 30 天，回答有界性与维持代价。

|---|---|---|
| 无量纲状态 [x, y, z, ẋ, ẏ, ż] | [0.8087346541, 0, 0, 0, 0.5158236131, 0] | [0.7501227262, 0, 0, 0, 0.6001535514, 0] |
| 周期 | 13.6608 天 | 18.2144 天 |

## 2.3 缺陷归零与映射修正（摘要）

- **力历元冻结缺陷**：场景首版未把积分时间同步入力评估，导致月球第三体按 t=0 冻结求值。经自查发现后按机制归零：新增回归测试（先红）→ 修复 → 复测绿 → **缺陷版 30 天实验数据全部作废留档、修复后重跑**（CR-LS-02）；
- **映射修正**：CRTBP→ECI 转换补入质心→地心偏移（μ·L≈4,668 km）及对应速度项，修正后端到端验证通过（CR-LS-03）。

两处修正均不涉及判据；红/修/绿时间戳经质量组审计 [6]。

## 2.5 维持 Δv 估算方法与结论

一阶方法：以两体视半长轴漂移 δa 为目标量，单次近地点切向修正的代价 Δv≈(n/2)·|δa|（n 为初始视平均角速度，对应 13.66 天谐振）。实测：理想模型逐周期漂移 ≤170 km（数值零漂移），维持 Δv≈0；真实星历下至第二个近地点（24.81 天）近地点 −5.2×10⁴ km，等效一次修正≈125 m/s（≈5 m/s/天）。多脉冲优化超出该专题边界。

## 2.6 独立验证与回归

- 闭合残差与积分步长无关（5,000↔80,000 步均为 1.02×10⁻⁹）——残差由求解器容差决定；
- RK4／DOP853／Radau 三积分器互差 ≤2.7×10⁻¹²；
- J2–J4 与势函数有限差分一致；跨积分器、步长敏感性证据齐全；
- 回归：LS 套件 51/51（502 s）；含既有回归的全量 297/297（见第四篇 §4.3）。



## 第三篇　低近地点族域与能量账本（AS 专题）


## 3.1 问题与目标

AS 专题面向概念所要求的低近地点几何（近地点 ≤200–300 km、远地点近月球、航天器每绕地球 2 圈对应月球 1 圈），设置三个问题：**AS-Q1** 严格周期解是否存在及求解策略；**AS-Q2** 单圈大气损耗与月球做功的能量收支是否闭合；**AS-Q3** 能力沉淀（七项，含 CR-AS-01 加速内核 [10]）。问题设计明确“负结果同样按留档规范交付、不设必须找到”[7]。

## 3.2 求解策略与共振约定

按概念口径确立约定：**p 个航天器惯性周期 : q 个月球周期**（2:1 即航天器惯性周期 13.6608 天；对称截面时刻即一个 T_sc，旋转系闭合周期 27.32 天）。求解工具箱包括：连续法/同伦驱动、线搜索牛顿对称打靶（基于与参考实现逐位一致的 numba fp64 编译内核）、自适应步长 RK4（近地点自动细分）、以及经健全性验证的多重打靶（parallel shooting）实现——在已知的 LS 严格解上三重打靶 3 代收敛至 1.2×10⁻¹³，证明实现无误。

## 3.5 求解加速与独立验证

- **加速内核（CR-AS-01）**：numba fp64 编译内核与参考实现逐位一致（抽样差 ≤4.4×10⁻¹⁶），单轨迹加速 6.1–24.8×；MLX/Metal fp32 筛选层 440 M 状态/秒（批量 ≥65,536 时饱和于 328–384 M 行·步/秒），仅作筛选、缺省自动降级——fp64 精确性由 CPU 路径保证；
- **独立验证**：内核逐位、步长/多积分器一致（自适应 vs DOP853 差 6.4×10⁻⁸）、事件检测、负结果重放四类全过；验收脚本五项全项 PASSED；
- 附：e≈0.98 轨道下 DOP853 在 rtol=10⁻¹¹ 时自身误差约 1.6×10⁻⁶，高保真复核须 ≤10⁻¹³（已入遗留清单）。



## 第四篇　结论与展望


## 4.1 总体结论

两轮专题把原始项目“概念齐备、结果为空”的状态推进为一条**闭合的证据链**（两轮专题结论速览见表~\ref{tab:1-1}）：

1. **严格求解已解决**：2:1／3:2 共振族的严格周期解（闭合 10⁻⁹ 量级、Jacobi 漂移≈0）与系统化求解流程在 LS 专题交付，并经缺陷归零与映射修正后在高保真链路中复现验证；
2. **摄动有界性已有明确结论**：LS 严格解 30 天有界；理想模型精确保形、真实星历不保形（含一次 1.77×10⁴ km 月交会）；
3. **低近地点族域为负/部分结果**：概念所要求的低近地点严格解在已勘测域内未找到，方法链与限定表述完整留档；
4. **能量机制获定量刻画**：在近失解几何上，“阻尼-月补”在能量意义上充裕（≈92×），未平衡、相位未闭环；J2 进动是比阻力更主要的对手——这为“若继续，问题应换成什么”给出了直接输入。
