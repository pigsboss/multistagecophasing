## 一、阶段任务与依据

- 目标：L2（编队协同）从"未接通的组件骨架"到"经测试验证的编队闭环"；
- 依据：DD-001 v1.1（R-L2-01～08）、DD-003 v1.1（T-L2-001～009，含 CRTBP 案例）、DD-002 工作包 WP-2.1～2.5。

## 二、开发内容（做了什么）

1. 主循环按五步时序重写：物理积分 → ISL 测量 → 路由 → 编队 GNC → 时钟/质量更新；
2. 接通 `FormationController.update()`：三段式状态机（生成/保持/重构）、时延 STM 补偿、目标跟踪——原先只取了控制增益 K，其余全部未生效；
3. 坐标系统一为 LVLH 旋转系口径：测量含 ω×Δr 输运项、控制用同一变换转回惯性系；速度由连续测量差分估计（替换占位零值）；
4. 物理环境注册真实引力（中心引力+J2 或 CRTBP），积分器统一 RK4——消除"零引力传播"；
5. ISL 链路全部接通：天线（含噪声）→ 路由器（50 ms 延迟/抖动/2% 丢包）→ 从星 GNC；帧统计可核对；
6. 新增冲量平滑器（MIB 量化，铁律 3），挂在推力器入口；天线/推力器加入随机种子，测试可复现；
7. 补全第三态：外部重构指令触发 KEEPING → RECONFIGURATION → 重收敛。

开发中发现并处理的问题（择要）：

- 增益—执行器量级不匹配：LQR 指令在 km 级偏差下可达 ~450 N，而默认推力器上限 1 N，导致全程饱和、控制失效；按闭环设计量级将 L2 测试/示例配置调整为 50 N 后恢复正常（"首跑失败 → 定位 → 修复"全程留痕）。

## 三、测试结果（验了什么）

- L2 专项测试 **10/10 通过**（47.7 s）；全量回归 **263/263 通过**（91.9 s）；
- 关键实测：

| 项目 | 结果 |
|---|---|
| CW 编队（0.3 天） | 稳态 RMSE **0.076 / 0.089 m**；速度 5.2 / 5.3 mm/s（门限 1 m / 10 mm/s） |
| CRTBP 编队（0.5 天，日地 L2） | 末 6 h RMSE 7.7 / 8.5 m；速度 0.38 / 1.07 mm/s（校准门限 10 m） |
| 时延/丢包鲁棒 | RMSE 0.012 m（基准）vs 0.091 m（50 ms 延迟 + 2% 丢包），均 ≤1 m |
| ISL 链路 | 帧守恒成立；丢包率 1.99% ≈ 配置值 2% |
| 重构态 | 触发 → 迁移 → 重收敛成功，末期 RMSE ≤1 m |
| 燃料账单 | 力积分与报表 ΔV 一致（<1%） |

- 证据：`workbench/design_dev/evidence/M2/` 与 `evidence/ALL/`（含最终回归日志）。

## 四、校准与变更（3 项，均经专家组确认）

1. CRTBP 稳态判据：暂定 ≤1 m → **校准 ≤10 m**（实测 7.7/8.5 m；DD-003 原注明"P2 前复核"）；
2. 鲁棒判据：固定 2× 比值 → **≤max(2×基准, 0.1 m) 且 ≤1 m**（基准处于估计器噪声底，比值判据不适用）；
3. 推力器上限：L2 测试/示例配置用 50 N（与闭环设计量级匹配；组件默认值未变）。

## 五、遗留与技术债（转入下阶段）

1. 弃用告警迁移（约 3.1 万条）——计划 M3 前处理；
2. 噪声追逐成本优化（采集段 ΔV≈114–123 m/s、稳态 ~50 m/s/天量级）——滤波带宽/增益折衷，P2+；
3. 性能基线对照自 M3 起纳入测试报告；
4. L2 红基线未按"先跑红日志"形式留档（以静态证据替代）——已记录，M3 起强制恢复"测试先行跑红"。
