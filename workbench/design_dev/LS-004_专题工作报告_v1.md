本专题以"问题牵引、沉淀能力"为原则，解决三个问题（LS-001）：

## 3 实现与关键调试记录

### 3.1 对称周期求解器（垂直截面判据）

设计变量 (x0, vy0)；在 t=T/2 要求垂直穿越 x 轴：残差 r=[y(T/2), ẋ(T/2)] → 0，由平面 CRTBP 对称性保证全周期闭合；收敛后以全周期积分复核全状态闭合与 Jacobi 漂移（解析雅可比 + 阻尼牛顿/SVD 最小二乘步）。

**2:1（G1 应达项）**：state_nd = [0.8087346541, 0, 0, 0, 0.5158236131, 0]；半周期截面残差 8.5×10⁻¹¹；全状态闭合 1.02×10⁻⁹（≤1e-8）；Jacobi 漂移 ≈ 0（≤1e-10）；34 次迭代；周期 13.6608 天（=地月特征周期的 π 倍，即 2 个航天器径向周期对应 1 个朔望周期）。

**3:2（R-LS-1 争取项）**：一次候选（0.80, 0.95）即收敛——state_nd = [0.7501227262, 0, 0, 0, 0.6001535514, 0]；半周期残差 5.25×10⁻⁹；全状态闭合 9.48×10⁻⁹（≤1e-8）；Jacobi 漂移 3.5×10⁻¹⁶；29 次迭代；周期 18.2144 天。

**几何复核（地心半径）**：2:1 解近地点 315,546 km / 远地点 456,583 km，节律 13.66 天（近地点在 13.66/27.32…，远地点在 6.83/20.49…），与理想月球最小距离 68,854 km。

### 3.2 初值系统化扫描（CR-LS-01）

首轮红测试的网格（x0∈[0.75,0.95]×vy∈[0.85,1.05]）不含真实周期族（族位于 vy≈0.42–0.60），扫描零收敛——**这是网格假设问题，不是求解能力问题**（严格求解器从 (0.85,0.95) 出发仍能收敛到族上）。经复扫将网格修正为 x0∈[0.78,0.86]×vy∈[0.44,0.60]（5×5），粗扫 22/25 收敛，精修（polish，≤6 个）全部达标；判据不变（≥3 个收敛初值、闭合 ≤1e-8）。验收脚本同步修正并收紧内部求解容差（1e-8→1e-10，判据不变）。变更单 CR-LS-01，见 §5。

### 3.3 变分矩阵与 ThirdBodyGravity

- `variational_matrix_nd()`：CRTBP 解析雅可比，与有限差分逐列核对通过（T-LS-001）；
- `ThirdBodyGravity`：a = μ₃[(r₃−r)/|r₃−r|³ − r₃/|r₃|³]（直接项+间接项），与手算解析式逐点一致（rtol 1e-12）、零质量极限为零、环境注册可求和（T-LS-004）。

### 3.4 带谐重力场 J2–J4（含 J4 推导修正）

重写 `high_order_geopotential.py` 为单一公式来源的 J2–J4 带谐（势口径 V=-(μ/r)ΣJₙ(Re/r)ⁿPₙ，a=−∇V）。实现过程中发现并修正 J4 加速度推导错误（a₄ 的 P₄ 导数项系数）；修正后与势函数有限差分梯度全组合一致（T-LS-005，rel<1e-5；J2 极限与 `J2Gravity` 逐位一致 rtol 1e-14）。

### 3.5 场景与 CRTBP→ECI 映射（CR-LS-03）

`EarthMoonResonanceSimulation`：J2000 ECI 自由演化（中心引力 + J2–J4 + 月球第三体（回调/SPICE）+ 简化指数大气），DOP853 自适应积分，输出 HDF5（epochs/states/altitude_m/moon_distance_m/energy_m2s2）。

**映射修正（CR-LS-03）**：CRTBP 归一化以质心为原点，而 ECI 以地心为原点；原映射漏掉质心→地心偏移 μ·L（本专题参数下 4,668 km）及速度对应项。修正后映射为 r_eci = L·(x_nd·d̂ + y_nd·ŷ) + μ·L·d̂、v_eci = L·ω·v_nd(旋转基) + ω⃗×r_eci。T-LS-006 同步更新（含绝对量断言）。修正后的端到端验证：把严格 2:1 解映射入 ECI 并以理想圆轨道月球积分 30 天，**复现 CRTBP 严格解**——远地点 6.85/20.54 天（参考 6.83/20.49 天）、近地点 13.69/27.40 天（参考 13.66/27.32 天）、远地点高度 457,095 km（参考 456,583 km，差 0.1%）。

### 3.6 技术归零记录（CR-LS-02：力模型历元冻结缺陷）

**缺陷**：`CelestialEnvironment` 的力评估使用 `self.epoch`，而场景 `accel(t, state)` 未把积分时间同步进环境（仓库既有惯例为调用方维护历元，见 `simulation/base.py`）。后果：时间相关力（月球星历）在全程积分中按 t=0 求值——**30 天实验实际演化了"冻结月球"**。该缺陷由设计组在实验数据复核中发现（受控解析积分 vs 场景结果不一致，逐力项分解定位）。

**归零过程**（红→修复→绿→重跑）：

1. 新增回归测试 T-LS-009（力按当前历元求值，解析对照 rtol 1e-9）→ 跑红：`20261010_101634_LS_T-LS-009_red.log`（10:16:36）；
2. 修复：`earth_moon.py` 的 accel 闭包同步 `env.epoch = t`（10:16:56）；
3. 复测绿：`20261010_101702_LS_T-LS-006_009_green.log`（10:17:04）；
4. 影响处理：缺陷版本全部实验数据**声明作废**并留档（`results/high_fidelity_pre_fix/`、`results/high_fidelity_circular_pre_fix/`），全部实验在修复后重跑。缺陷版与修复版对比（同一初值）：远地点 711,755 km（冻结）vs 456,824 km（理想月球复现），说明缺陷后果显著、必须作废。

变更单 CR-LS-02，见 §5；质量组按 O-9 审计了红/修复/绿时间戳顺序（QM-LS-002）。

## 4 30 天高保真演化实验（G3）

### 4.1 设置

同初态（2:1 严格解经 CR-LS-03 映射）、同积分器（DOP853，rtol=3e-10、atol=1e-6、采样 600 s）、三组对照：A=J2 only；B=+月球第三体；C=B+简化指数大气（面质比 0.02 m²/kg）。两套模型层级：**理想圆轨道月球**（离线、可复现、作为对照）与 **SPICE 真实月球星历**（DE 内核，主结论）。月球星历以 60 s 网格缓存插值加速。

### 4.2 结果（修复后）

| 组 | 模型 | 30 天有界 | 高度 min / max / final（km） | 节律（高度极值时刻） |
|---|---|---|---|---|
| A | J2 only（该高度 J2≪中心项，等效开普勒） | ✅ | 309,168 / 902,825 / 897,791 | 单远地点 27.6 d（P≈55.2 d） |
| B（理想圆月） | +理想圆轨道月球 | ✅ | 309,168 / 450,724 / 362,870 | 远地点 6.85 / 20.54 d；近地点 13.69 / 27.40 d = **严格解节律** |
| B（SPICE） | +真实月球星历 | ✅ | 256,939 / 534,894 / 422,363 | 远地点 11.03 d；近地点 24.81 d；29.54 d 月球近距 17,727 km |
| C（SPICE） | +简化大气 | ✅（与 B 全同，max|Δstate|=0） | 同 B | 阻力在 ≥2.5×10⁵ km 高度可忽略 |

### 4.3 结论（R-LS-3 口径）

1. **有界性（G3 核心）成立**：三组、两套模型层级下 30 天全部保持有界（r_max ≤ 5.4×10⁵ km ≪ 逃逸判据 2×10⁹ m；无再入）。
2. **理想模型下严格解精确复现**（节律、远地点高度与 CRTBP 参考差 0.1%；逐周期近地点差 ≤170 km，源于 60 s 缓存/质量常数微差/J2，无系统漂移）——求解-映射-场景链路闭环验证成立。
3. **真实星历下有界但不保形**：真实月球（距地 4.02×10⁸ m、含偏心/倾角/相位差）使轨道去相位：首个远地点推迟至 11.03 d 且抬高至 534,894 km（+7.8×10⁴ km），近地点降至 256,939 km（−5.2×10⁴ km）；29.54 d 形成一次 1.77×10⁴ km 的月球近距交会（a_osc 由 4.66×10⁵ km 降至 2.30×10⁵ km，能量交换显著）。**"严格共振相位在真实模型下不保持"是本次实验的明确结论**（非失败）。
4. **大气**：本专题求解的这条 2:1 解全程 ≥2.5×10⁵ km 高度，简化大气影响在 30 天内为数值零（B 与 C 逐位相同）——"近地点大气阻尼 - 远地点月球补偿"能量平衡机制**在这条解上不触发**（其近地点远离大气）；概念所要求的低近地点（≤200 km、大气穿越）成员**不属本专题求解范围**（未勘测族域）——此为本实验对 LS-Q2 的澄清（勘误 2026-10-10：原文"对 2:1 大偏心率轨道，近地点远离大气"表述过度泛化，仅对解本身成立）。

### 4.4 维持 Δv 估算（方法 + 数量级，非优化结果）

**方法（一阶）**：以两体视半长轴漂移 δa 为目标量，在近地点一次切向修正的代价 Δv ≈ (n/2)·|δa|（n 为初始视平均角速度，n=√(μ/a₀³)≈1.32×10⁻⁶ rad/s，对应 13.66 天谐振）；等价地也可用"共相近地点高度漂移"折算。

**实测**：理想月球下逐周期近地点漂移 ≤170 km（数值零漂移），维持 Δv ≈ 0；真实星历下至第二个近地点（24.81 d）近地点 −5.2×10⁴ km，等效 |δa|≈1.9×10⁵ km ⇒ 一次修正 ≈ 125 m/s（≈5 m/s/天平均）；此后月球交会主导轨道再定向。**边界声明**：多脉冲/在站策略与优化超出本专题非目标；本报告只给出量化方法与非保守数量级。

### 4.5 模型层级与近似声明（R-LS-3）

CRTBP 平面归一化（质心原点）→ ECI 地心（μ·L 偏移，CR-LS-03）；理想月为圆轨道 3.844×10⁸ m；真实月为 SPICE 瞬时状态、60 s 缓存插值（插值误差 ≪ 摄动量级）；大气为简化指数模型（本实验未触发）；J2–J4 带谐；全程无控制、无太阳光压/SRP、无三体外的其他摄动；质量常数取场景内固定值（与 CRTBP 自洽 μ 存在 ≈0.05% 微差，已含在对照的 0.1% 一致性内）。
