## 3 实现明细

### F-L3-1 Stewart 平台运动学（R-L3-02）
- 逆解解析 + 正解牛顿（数值雅可比）；**调试发现两类几何奇异**（均已修复并留注释警示）：
  1. 均布 60° 的"全对称"构型雅可比**秩亏 3 维**（6 DOF 退化）；
  2. 顶/底锚点对间距相同（α_b=α_t）时两构型互为"同伦像"，中心位形奇异——经典 6-6 须 **α_b≠α_t**（最终取 8°/14°）。
- 结果：σ(J)=[1.84, 1.17, 1.17, 0.022, 0.022, 0.014]（全秩）；闭环误差 **3.97e-15**（门限 1e-9）。

### F-L3-2 快摆镜 FSM 组件（R-L3-02）
2 轴二阶动力学 + 行程限幅（500 Hz / ζ0.7 / ±1 mrad），RK4 离散步进。

### F-L3-3 平台-载荷双层模型与解耦校验（R-L3-01）
质量比超限（默认 0.10）即抛 `PayloadDecouplingError`（检查并报警，不静默降级）；平台抖动=确定性频点（1–80 Hz）+ 带限随机相位分量（1–100 Hz），seed 可复现。

### F-L3-4 OPD 简化链路与稳定度工具（R-L3-03）
opd = κ·‖θ_res‖（κ=2×力臂=5 m/rad）；提供重叠 Allan 偏差工具（τ 平均）。

### F-L3-5 误差预算工具（R-L3-04）
RSS 合成 + 闭包校验 + 逐项实测超分配检出。

### F-L3-6 分层共相控制与闭环装配器（R-L3-05）
- 精调环（FSM）：PI + 滤波微分；粗调环（Stewart）：低增益慢积分；
- **调试发现**：微分项"设定值踢"主导阶跃超调（kd 越大超调反而 27%→63%），经增益网格搜索定参（kp=2.5/ki=800/kd=2e-4/ki_s=20）；
- 结果：RMS 抑制 22.3×（开环 8.07e-7 → 闭环 3.62e-8）、超调 5.5%、整定 11 ms。

### F-L3-7 技术债清理：弃用 API 迁移（O-11 ①，M3 前项）
`get_interpolated_state → get_state` 全量迁移（生产 4 处 + 测试 10 处），弃用兼容层保留；**全量回归告警 31,049 → 0**。
