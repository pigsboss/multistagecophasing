## 1 目的与范围

**目的**：为 MCPC 框架 L1–L4 级研制确立系统技术方案（目标、现状差距、分级方案、关键决策、接口、风险与验收准则），作为《工作策划》（DD-002）与《测试大纲》（DD-003）的上位文件。

**范围**：
- **L1** 基准定标：单星绝对轨道闭环（修复与验证）；
- **L2** 编队协同：相对动力学、星间链路、三阶段控制器的**接通**与验收；
- **L3** 载荷闭环（原理原型）：平台-载荷双层模型、Stewart/快摆镜、OPD 共相链路；
- **L4** 样机鉴定（工程化原型）：6-DOF 姿轨耦合、硬件非线性、蒙特卡洛评估与 HITL 接口预留。
- L5 不在本次范围（仅留接口，不实现）。

**生效条件**：本文件与 DD-002、DD-003 经【评审专家】评审并给出"可以生效"结论、【设计开发】完成修订答复后方可生效；未生效不得据以启动开发（QM-001 §3 叫停条件 1）。

## 3 现状基线与差距分析（证据级）

### 3.1 总体

现行测试 241 项全绿（38.6 s），但**端到端物理正确性缺乏测试保障**：L1 三体（CRTBP）通路自洽，二体通路存在物理缺陷；L2 为未接通的组件骨架。测试绿与物理正确性之间不存在因果保证（已实证）。本方案全部差距均附代码/运行证据。

### 3.2 L1 差距

| 编号 | 缺陷 | 证据 | 后果 |
|---|---|---|---|
| D1 | **二体通路缺中心引力** | `physics/models/j2_gravity.py:22` 仅 J2 摄动项；`simulation/twobody/base.py:101-104` 仅注册 J2(+大气阻力)；实测初始状态环境合力 1.1×10⁻² m/s² vs 理论中心引力 8.13 m/s²（约 740 倍） | 默认增益下 LEO ΔV≈4.7×10⁵ m/s/天；调小增益（5×10⁻⁹）后报表"正常"但 2.4 h 内轨道半径 7000 km→65 379 km 飞离 |
| D2 | **跟踪误差链路失效** | `gnc_subsystem.py:43,182` 唯一写点在 `compute_control_force`；LEO/GEO 覆写 `_compute_control`（`leo.py:131`、`geo.py:92`）从不调用 → `last_tracking_error` 恒零；显示（`base.py:128-131`）、HDF5（`base.py:230`）全部失真 | 评审 v2/v3"误差收敛"结论不可信；调参可掩盖缺陷 |
| D3 | **分级 CLI 与实现不符** | `run.py:76-88`：leo/geo 忽略 `--level`；sun_earth_l2 `--level≥2` 抛 AttributeError | 文档承诺的分级能力不存在 |

**CRTBP 通路正向证据**（防回归基线）：Halo 场景 0.5 天实测跟踪误差 2999 m→526 m 收敛、轨迹有界；Jacobi 守恒测试 <1e-10。

### 3.3 L2 差距

| 编号 | 缺陷 | 证据 |
|---|---|---|
| D4 | **主循环未接通控制器** | `formation_simulation.py:176-188` 只用 `controller.K`，从不调用 `FormationController.update()`——三阶段状态机、时延 STM 补偿、网络帧全程不生效；日志 mode 恒 GENERATION（`:217-218`） |
| D5 | **坐标系混算** | 误差用绝对系状态差（`:179-183`），目标 `formation_targets` 为 LVLH（`run_formation_crtbp.py:31-35`） |
| D6 | **零引力传播 + 积分器不一致** | 环境未注册任何力模型（`:74-78`）→ 加速度恒 0；显式欧拉（`:172`）与单星 RK4 不一致 |
| D7 | **配置未被消费** | `run_formation_crtbp.py:75-91` 传入 ISL/推力器/路由器参数，`FormationSimulation` 不使用 |
| D8 | **违反 L2 铁律 1** | 控制器直接读绝对真值（REF-02：物理真值与赛博认知绝对屏障） |

测试侧证据：`tests/test_l2_integration.py` 仅断言"运行不崩 + 相对距离 ≤1.1×"，在零引力自由空间中必然通过。

### 3.4 L3/L4 差距

- **L3**：`cyber/payload_ctrl/`、`physics/components/mechanisms/` 为空目录；无平台-载荷双层模型、无 OPD 链路、无误差预算工具；`spacetime/attitude/__init__.py:3-5` 断链导入（引用不存在的 `config/models/interpolated` 模块），既有姿态资产不可用。
- **L4**：无 6-DOF 姿态动力学、无传感器噪声谱（Allan 方差）、无 HITL、无蒙特卡洛评估；`components/actuators/thruster.py` 已有死区/饱和/噪声底盘可复用。

### 3.5 差距-目标汇总

| 级别 | 能力域 | 现状 | 目标状态 |
|---|---|---|---|
| L1 | 单星绝对闭环 | 缺中心引力、指标失真、分级失真 | 可信闭环 + 物理门限 + 回归保护 |
| L2 | 编队协同 | 组件齐备但主循环未接通 | 五步时序闭环 + 鲁棒验收 + 铁律合规 |
| L3 | 载荷共相 | 空白 | 双层原型 + OPD 共相闭环 + 误差预算 |
| L4 | 工程化 | 空白 | 6-DOF + 硬件非线性 + 评估 + HITL 接口 |

## 4 总体技术方案

### 4.1 架构原则（沿用并强化）

1. 三域解耦 + `ids.py` 契约化（REF-01/02）；
2. **不越界开发**：L2 不引入硬件摩擦模型；L3 用简化运动学/传递函数；真实硬件非线性留到 L4；
3. **低级为高级基准**：L2 依赖 L1 标称基准可信；L3 建立在 L2 编队闭环上；L4 建立在 L3 载荷链上；
4. **测试先行（TDD）**：每级功能先落测试（DD-003）再实现；
5. **证据可复现**：结论可由命令/数据复现；文献引用一律用 LIT 编号。

### 4.2 通用技术要求

| 编号 | 要求 | 针对缺陷 |
|---|---|---|
| G-01 | 力模型原子化：中心引力作为**独立模型**新增；各摄动模型单一职责；环境合力=注册模型之和（禁止隐式项） | D1 |
| G-02 | 指标唯一通道：跟踪误差只由 GNCSubsystem 计算记录一次，显示/日志/报告同源 | D2 |
| G-03 | 坐标系与积分器一致性：同一仿真统一积分器与坐标系；跨系转换显式且 float64 | D5/D6 |
| G-04 | 物理不变量测试基线（守恒/量级/边界/回归）先于实现落地 | D1/D2 类问题 |
| G-05 | 防"调参掩盖"：门限基于物理量级（ΔV/半径/能量），并配"报表—数据一致性"测试 | D1+D2 组合教训（LIT 教训） |
| G-06 | 文献与数据管理：方案/门限引用 LIT 编号；新增文献先入库后引用 | REF-04 |

### 4.3 分级路线

L1→L2→L3→L4 顺序推进；每级设里程碑评审（DD-002）；上一级未通过不得进入下一级。

## 5 分级技术方案

### 5.1 L1（修复与定标）

| 需求 | 内容 | 验收（暂定，评审确认） |
|---|---|---|
| R-L1-01 | 新增 CentralGravity 力模型（−μr/\|r\|³）并注册进二体场景 | 单元相对误差 <1e-12；标量/向量化一致 |
| R-L1-02 | 跟踪误差链路唯一通道化（GNCSubsystem 计算 + 记录） | `last_tracking_error` 与 nav−nominal 相对一致 <1e-9；HDF5 记录非零且收敛 |
| R-L1-03 | LEO 闭环物理门限 | 1 天 ΔV ≤5 m/s/天（工程参考 ~0.5 m/s/天）；半径漂移 ≤1 km/天；不飞离 |
| R-L1-04 | GEO 闭环物理门限 | 1 天 ΔV ≤0.5 m/s/天 |
| R-L1-05 | CRTBP/Halo 回归保护 | Jacobi 守恒 <1e-10；跟踪误差有界收敛 |
| R-L1-06 | 分级接口与实现一致（修补或明确移除） | CLI、文档、实现三者一致 |

技术要点：新增 `physics/models/central_gravity.py`；`twobody/base.py` 注册；LEO/GEO 控制路径改经统一 GNC 通道；`run.py` 分级修正。

### 5.2 L2（接通与验收）

| 需求 | 内容 | 验收（暂定，评审确认） |
|---|---|---|
| R-L2-01 | 主循环按 REF-02 §3.1 五步时序重构：物理积分→ISL 测量→路由→GNC（含 `update()`）→时钟步进 | 每步调用 update()（计数断言）；GEN→KEEPING 实际迁移 |
| R-L2-02 | 坐标系严格化：相对误差/目标统一 LVLH，跨系转换显式 | 解析场景方向/幅值比对 <1% |
| R-L2-03 | 物理环境注册（中心引力+J2 或成套 CRTBP 相对框架）；积分器统一 RK4 | 注册表非空；与 L1 同源动力学 |
| R-L2-04 | ISL 链路接通（天线→路由[延迟/抖动/丢包]→控制器）；推力器（死区/MIB）接线 | 帧守恒 N(1−p)±3σ；冲量等效一致性 <1% |
| R-L2-05 | 编队闭环验收门限 | 三星场景 0.1 天收敛至 ±1 m / ±10 mm/s（稳态 RMSE，暂定）；时延 0.05 s±0.01 s + 丢包 2% 下劣化 ≤2× |
| R-L2-06 | 燃料账单可信 | 各星 ΔV 与 ∫\|F\|/m 一致 <1% |
| R-L2-07 | 铁律合规（物理/赛博隔离、契约化、时钟分离/冲量平滑） | 专项测试 + 代码评审 |

### 5.3 L3（原理原型）

| 需求 | 内容 | 验收（暂定，评审确认） |
|---|---|---|
| R-L3-01 | 平台-载荷双层模型（载荷为挂接简化体） | 接口/质量特性一致 |
| R-L3-02 | Stewart 平台/快摆镜运动学映射 | 指令→末端位姿误差 <1e-9（数值闭环） |
| R-L3-03 | OPD 简化链路（几何 + 平台扰动 → 光程差残差） | 扰动谱下残差 RMS ≤ λ/10 @500 nm（暂定） |
| R-L3-04 | 级间误差预算工具（自动合成校验） | 预算闭合：合成 ≤ 总预算 |
| R-L3-05 | 分层控制（平台粗调 LQR + 载荷精调） | 阶跃超调 ≤20%、稳定收敛 |

### 5.4 L4（工程化原型）

| 需求 | 内容 | 验收（暂定，评审确认） |
|---|---|---|
| R-L4-01 | 6-DOF 姿轨耦合（四元数姿态动力学） | 无控自由演化角动量守恒 <1e-10 |
| R-L4-02 | 执行器非线性（死区/MIB/延迟）+ 传感器噪声谱（Allan 方差近似） | 边界值行为符合定义；谱斜率区间校验通过 |
| R-L4-03 | 蒙特卡洛鲁棒边界评估 | 参数扫描通过率 ≥95%（N≥50，暂定） |
| R-L4-04 | OPD/指向极值评估 | 任务扰动谱下 P95 ≤ 阈值（暂定） |
| R-L4-05 | HITL 接口预留（契约 + 时间步握手，mock 验证） | 接口测试通过（mock 硬件） |

## 6 关键设计决策

| 编号 | 决策 | 理由 | 影响 |
|---|---|---|---|
| D-01 | 中心引力以**新增独立模型**接入，不改 `J2Gravity` 语义 | 单一职责；J2 仍是"摄动"项，防混淆 | 二体场景注册两模型 |
| D-02 | 跟踪误差**唯一通道**：由 GNCSubsystem 统一计算记录，各场景控制路径必须经其输出 | 治 D2 根因，而非修补显示 | LEO/GEO 控制路径重构 |
| D-03 | **禁止以调小增益掩盖物理缺口**：门限基于物理量级，并配报表-数据一致性测试 | 评审 v2"5e-9 调参"教训 | DD-003 含防回归专项 |
| D-04 | L2 按 REF-02 五步时序重构，`controller.update()` 为强制路径 | 铁律合规（D4/D8） | 主循环重写 |
| D-05 | L2 参考系统一 LVLH；跨系转换必须成对且 float64 | 治 D5 | 复用 `math_tools` 通道 |
| D-06 | L3 严格"不越界"：简化运动学/传递函数 + 解耦假设显式化并校验 | REF-01 原则四 | 增加假设适用性测试 |
| D-07 | L4 先契约后模型：HITL 接口与数据契约先行 | 降低返工 | 接口先行实现 |
| D-08 | 文献引用制度化（LIT 编号 + 先入库后引用） | 证据链完整 | 文档模板含引用列 |

## 7 接口与数据契约

- **复用**：`Telecommand` / `Telemetry` / `FormationState` / `ISLNetworkFrame`（现有，保持稳定）。
